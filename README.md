## About Me

I work across the end-to-end data and business intelligence lifecycle, from building data pipelines and data warehouses to developing analytical models, interactive dashboards, and business insights.

My focus is on transforming raw operational data into reliable, scalable, and actionable BI solutions.

### What I Do

* Build ETL/ELT pipelines to extract, transform, and load data
* Design and develop Data Warehouses and analytical data models
* Work with Star Schema and dimensional modeling
* Develop BI solutions using SQL Server, SSIS, Power BI, and DAX
* Build interactive dashboards and KPI-driven reports
* Perform data analysis and identify trends, patterns, and performance gaps
* Automate reporting workflows and improve data accessibility
* Use Python for data cleaning, analysis, and automation
* Translate business requirements into scalable data and BI solutions
