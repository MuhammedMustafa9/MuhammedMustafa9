## 🎯 Role: Data Analyst
A data-driven analyst specialized in transforming raw datasets into actionable insights.  
I build interactive dashboards, automate reporting workflows, and support decision-making through statistical analysis, predictive modeling, and KPI performance tracking.

### Core Functions I Perform:
- Collecting, cleaning, and structuring large datasets using SQL & Python  
- Designing BI dashboards in Power BI & Tableau for executive reporting  
- Analyzing trends, forecasting performance, and identifying anomalies  
- Building automated reporting pipelines (ETL/ELT)  
- Tracking KPIs and delivering data-driven recommendations  
- Supporting business teams with insights that optimize operations
